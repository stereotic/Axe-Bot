# Развертывание Telegram-бота на сервере (подробная инструкция для новичков)

## Введение

Эта инструкция поможет вам развернуть вашего Telegram-бота на удаленном сервере, чтобы он работал автономно 24/7, даже когда ваш компьютер выключен. Мы будем использовать сервер с Linux (Ubuntu/Debian), Node.js, PM2 и другие инструменты.

**Время выполнения**: 20-30 минут (первый раз дольше).

**Что нужно знать заранее**:
- Терминал — черное окошко для команд (на Windows: Win + R → `cmd` или `powershell`).
- SSH — способ подключения к серверу по интернету.
- Git — система контроля версий (если код на GitHub).

**Предварительные требования**:
- Доступ к серверу: IP вашего VPS, логин и пароль или SSH-ключ.
- Файлы бота на вашем компьютере (папка `C:\Users\Артем\Desktop\projects\BLACK-BET TEAM\Axe bot`).
- Токен бота от @BotFather (BOT_TOKEN).
- Желательно: аккаунт на GitHub для хранения кода.

## Шаг 1: Проверка подключения к серверу

Сначала убедитесь, что сервер доступен.

На вашем компьютере откройте терминал и выполните:

```bash
ping YOUR_SERVER_IP
```

Если видите ответы типа "Reply from 170.168.103.10", сервер работает. Если нет — проверьте интернет или данные.

## Шаг 2: Подключение к серверу по SSH

SSH — это безопасное подключение к серверу.

В терминале на вашем компьютере:

```bash
ssh root@YOUR_SERVER_IP
```

- Когда спросит "Are you sure you want to continue connecting?" — введите `yes`.
- Введите пароль вашего сервера (при вводе он не отображается).

Если подключение успешно, вы увидите приглашение вроде `root@ubuntu:~#`. Теперь вы "внутри" сервера. Все команды выполняются на сервере.

**Важно**: Не закрывайте это окно терминала — оно ваше соединение с сервером.

## Шаг 3: Обновление сервера

Сервер нуждается в обновлениях для безопасности и стабильности.

```bash
apt update
apt upgrade -y
```

- `apt update` — обновляет список пакетов.
- `apt upgrade -y` — устанавливает обновления автоматически (`-y` значит "да" на все вопросы).

Подождите 1-2 минуты.

## Шаг 4: Установка Node.js и npm

Node.js — среда для запуска JavaScript-кода бота. npm — менеджер пакетов.

```bash
apt install -y nodejs npm
```

Проверьте установку:

```bash
node --version
npm --version
```

Должно показать версии (например, v18.x.x и 9.x.x).

## Шаг 5: Установка Git

Git нужен для копирования кода из репозитория (если используете GitHub).

```bash
apt install -y git
```

Проверьте:

```bash
git --version
```

## Шаг 6: Установка PM2

PM2 — менеджер процессов. Он запускает бота в фоне и перезапускает при сбоях.

```bash
npm install -g pm2
```

Проверьте:

```bash
pm2 --version
```

## Шаг 7: Создание директории для проекта

Создадим папку для файлов бота.

```bash
mkdir -p /root/axe-bot
cd /root/axe-bot
```

- `mkdir -p` — создает папку (если нет).
- `cd` — переходим в папку.

## Шаг 8: Копирование файлов проекта на сервер

Есть два способа. Выберите один.

### Способ 1: Через Git (рекомендуется)

Если ваш код на GitHub:
1. Создайте репозиторий на GitHub.com (бесплатно).
2. Загрузите файлы из папки `C:\Users\Артем\Desktop\projects\BLACK-BET TEAM\Axe bot` в репозиторий.
3. Получите ссылку на репозиторий (например, `https://github.com/your-username/your-repo.git`).

На сервере:

```bash
git clone https://github.com/your-username/your-repo.git .
```

Замените ссылку на свою. Точка в конце копирует в текущую папку.

### Способ 2: Через SCP (прямое копирование)

Если Git не используете:
1. Откройте **новое окно терминала** на вашем компьютере (не закрывайте SSH-окно).
2. Выполните:

```bash
scp -r "C:\Users\Артем\Desktop\projects\BLACK-BET TEAM\Axe bot\*" root@YOUR_SERVER_IP:/root/axe-bot/
```

Это скопирует все файлы на сервер. Подождите (может занять время).

Вернитесь в SSH-окно и проверьте файлы:

```bash
ls -la
```

Должны быть: `bot.js`, `package.json`, `database.js` и т.д.

## Шаг 9: Установка зависимостей

Установите библиотеки, которые использует бот.

```bash
npm install
```

Это прочитает `package.json` и скачает нужные пакеты. Займет 1-2 минуты.

## Шаг 10: Настройка переменных окружения (.env)

Бот нуждается в секретных данных (токен, ID админов).

Создайте файл `.env`:

```bash
nano .env
```

В редакторе `nano` вставьте:

```
BOT_TOKEN=ваш_токен_от_BotFather
ADMIN_IDS=список_id_админов_через_запятую
# Добавьте другие переменные из вашего локального .env
```

- Сохраните: Ctrl + X → Y → Enter.

Проверьте:

```bash
cat .env
```

## Шаг 11: Запуск бота

Запустите бота с PM2.

```bash
pm2 start bot.js --name "axe-bot"
```

Проверьте статус:

```bash
pm2 status
```

Должно показать "axe-bot" со статусом "online".

Посмотрите логи:

```bash
pm2 logs axe-bot
```

Если видите "🤖 Бот запущен..." — все ок.

## Шаг 12: Настройка автозапуска при перезагрузке сервера

Чтобы бот запускался автоматически после перезагрузки сервера.

```bash
pm2 save
pm2 startup
```

Следуйте инструкциям на экране (обычно: скопируйте команду и вставьте ее).

## Шаг 13: Финальная проверка

1. В Telegram найдите бота и напишите `/start`.
2. Если отвечает — поздравляем! Бот работает.
3. Проверьте логи еще раз: `pm2 logs axe-bot`.

## Управление ботом

- **Остановить бота**: `pm2 stop axe-bot`
- **Перезапустить**: `pm2 restart axe-bot`
- **Удалить**: `pm2 delete axe-bot`
- **Посмотреть статус**: `pm2 status`
- **Логи**: `pm2 logs axe-bot`

## Обновление кода

Если изменили код:
1. Загрузите изменения на GitHub.
2. На сервере: `cd /root/axe-bot && git pull && pm2 restart axe-bot`

## Возможные проблемы и решения

- **Ошибка подключения SSH**: Проверьте IP, логин, пароль. Убедитесь, что сервер включен.
- **Бот не отвечает**: Проверьте BOT_TOKEN в .env. Логи покажут ошибку.
- **Пакеты не устанавливаются**: `npm cache clean --force` и повторите `npm install`.
- **Сервер не отвечает**: Возможно, firewall. На сервере: `ufw allow 22/tcp && ufw --force enable`.

## Безопасность

- Не делитесь паролем сервера.
- Измените пароль root: `passwd root`.
- Настройте SSH-ключи вместо пароля (погуглите "SSH key authentication").

Если застряли — покажите ошибку или скриншот. Удачи! 🤖
